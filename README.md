# My Personal Project

## CloudCapital

CloudCapital is a personal banking application developed in Java, delivering a smooth and intuitive financial 
experience. Its user-friendly interface enables easy financial management, transaction execution, and real-time 
monitoring of account activities. CloudCapital will be a completely online experience that serves a single user group - 
personal banking *clients*, who will solely have access to the platform through the java app.

This app is catered to anyone who wishes to track their banking activity through a simple and intuitive user-interface. 
Users can have a range of goal between maximizing savings, tracking personal cash flows and growing portfolio. 
CloudCaptial will be tailored to personal banking and not commercial banking to best streamline the user experience for 
individuals.

I am interested in this project because I find that current apps for tracking banking activities do not update as 
quickly (typically 3-5 business days to update transfers of funds) which allows misleading judgements of the amount a 
user possess in their *account*. With this app, as there are no communications between financial institutions, only the 
*withdrawal* and *deposit* activities of a *client's* account from an arbitrary financial institution (built into the 
application) will be tracked.


**Key Features**:

- Account Management: Effortlessly create and oversee multiple accounts, including savings and checking.

- Transaction History: Review detailed transaction records, including date, time, and amount information.

- Fund Transfers: Execute secure money transfers between accounts and to external bank accounts.

- Bill Payments: Conveniently settle bills within the app, ensuring prompt payments.

- Notifications: Receive instant notifications for transactions, account updates, and important announcements.

- User Profiles: Tailor user profiles with personal details and preferences.

- Experience the convenience and security of JavaBank as you navigate through its feature-rich functionalities, making banking tasks a breeze.

- Conversion Rates: Able to convert certain amounts across different fiat currencies


### User Stories

- As a client, I want to be able to add funds to my account
- As a client, I want to be able to withdraw funds from my account
- As a client, I want to be able to **open multiple accounts of any kind**
- As a client, I want to be able to **open different types of accounts**
- As a client, I want to be able to transfer funds between accounts
- As a client, I want to be able to **view my account totals and history**
- As a client, I want to be able to **view multiple account totals at once**
- As a client, I want to be able to download my transaction history for each account
- As a client, I want to be able to save my account data so that I can access it next time I use the application
- As a user, I want to be able to load my previous saved account date from so that I can continue from where I left off.
